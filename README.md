## ¿Qué es Kodevia?

Kodevia desarrolla sistemas a medida para pequeñas y medianas empresas. El foco está en automatizar procesos manuales — facturación, inventarios, gestión académica — con código limpio, documentado y sin dependencias innecesarias.

**Stack principal:** Java · Spring Boot · JPA/Hibernate · MySQL · REST APIs · JWT

---

## Qué encontrás en este repo

```
kodevia-portfolio/
├── frontend/               # Sitio estático (HTML + CSS + JS)
│   ├── index.html          # Página principal
│   ├── img/                # Imágenes locales (hero, stack, blog)
│   ├── docs/               # CVs descargables (ES / EN)
│   └── BACKLOG.md          # Backlog de desarrollo activo
├── backend/                # Pendiente — Spring Boot (próximamente)
└── .github/
    └── workflows/
        └── deploy.yml      # CI/CD: push a main → deploy automático en VPS
```

## Stack del sitio

| Capa | Tecnología |
|------|-----------|
| Frontend | HTML5 · CSS3 · JavaScript ES6 |
| Fuentes | Google Fonts (Roboto) |

| Contenedor | Docker + Portainer |

---

## CI/CD

Cada `push` a `main` dispara un deploy automático al VPS vía GitHub Actions. Ver `.github/DEPLOY-SETUP.md` para la guía de configuración completa.
